# NammaSpot brand rules

- **Palette:** warm paper cream for surfaces, deep burgundy for actions and linework, charcoal for body text; keep contrast comfortable.
- **Local detail, lightly used:** use kolam dots as small dividers or quiet background texture, never as dense decoration. Temple-border stripes belong at section edges, not around every card.
- **Illustration:** category icons are inline SVG, one-colour burgundy strokes on cream discs. Keep a consistent stroke weight, rounded joins and simple silhouettes; unknown categories use the generic spot pin.
- **Typography:** use restrained, readable sans-serif UI text and a serif accent for editorial category titles. Tamil copy should render naturally and never be treated as ornament alone.
- **Layout:** generous whitespace, compact labels, thin warm borders and soft shadows. Prioritise two-column category cards on phones and four columns on wide screens.
- **Motion and assets:** no external imagery for core discovery UI, no heavy motion, and honour `prefers-reduced-motion`.
